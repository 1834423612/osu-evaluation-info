# OSU 人员查询、身份与缓存

[English](../../people/directory.md) · 简体中文

已知 OSU 邮箱优先转换为精确账号查询，结果必须与账号或完整邮箱相同。仅姓名查询使用少量首尾名组合，但仍要求规范化完整姓名匹配；无法确认时保留未知。姓名相似不等于身份已验证。

员工类型来自全部已保存官方任职信息，包括教授各级、临床／实践／访问、讲师、荣休、研究和明确的研究生助教。其他研究生不因为学生身份就标成助教。部门与任职说明通过独立浮层展示，不挤压教师行。

只对可见教师启动查询，共享队列最多并发 2 个、启动间隔 350ms、可见延迟 250ms；重复身份合并。已缓存资料立即显示，背景课程卡片不批量查询人员。

缓存区分可靠身份、候选、未找到和请求失败，失败不伪装为空记录。照片通过固定来源和格式验证；无照片保留缩写头像。历史 PDF 职务与当前官方任职分开，不能写成现职。
