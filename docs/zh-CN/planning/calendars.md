# 日历与保存的课表组

[English](../../planning/calendars.md) · 简体中文

## 使用

页面默认展示三个独立官方来源：**学期与考试**、**假期与停课**、**注册与缴费截止**。它们读取共享校历数据库，不会向每个账号重复复制事件。打开来源可切换月视图、周视图或清单，点击日期条目查看完整标题和 Registrar 链接。来源栏显示最近一次成功采集时间，日期加载失败时提供重试。官方来源只读，可以作为组合日历的引用来源。

**新建日历**先提供个人日历、持续更新的订阅和组合日历三种方式。设置表单在保存前预览名称、图标与颜色。新建时尚未修改设置的日历不会触发未保存编辑提示。

学期模拟可以保存为独立课表组，或替换指定的已有组。课程变化会把旧组标为过期，不会自动覆盖班次。进入“我的日程”可重命名、编辑单个事件、选择图标与颜色、切换周视图和清单、导出 ICS。每个日历有小预览图，手机网格的七个星期标题保持在同一行。时间使用 America/New_York，包含夏令时。

可以在本地导入 ICS，登录后订阅 HTTPS/webcal ICS 地址，或组合已有日历。组合日历引用来源，来源变化会反映到组合视图。订阅事件只读，修改前可创建可编辑副本。导入上限为 2 MB、展开后 3,000 个事件；不支持或过量的重复规则会明确失败。一个工作区最多 40 个日历，浏览器存储空间可能更少；保存报错时请导出备份。

工作区打开时，远程来源超过一小时会刷新。分享订阅请求也可刷新最多两个过期来源，使用数据库租约和用户速率额度限制请求。失败时保留上次成功的事件。远程读取只允许公开 HTTPS 目标，重新验证重定向、固定 DNS 解析结果，并限制耗时和响应大小。不支持需要 Cookie 或交互登录的私密来源。

## 分享与订阅

选择一个或多个日历及允许查看的事件类型，默认勾选所有类型。公开昵称可选。有效期支持一天、一周、30 天或直到撤销。发布需要已验证账号和学校邮箱验证；学校邮箱访问权不代表在校身份。同一组日历会复用订阅地址，事件变化更新到原地址。撤销后原链接失效，再次发布会更换访问凭据。每个账号最多 50 个有效链接，每个链接最多包含 30 个日历。

接收者可以查看周视图，选择日历复制到自己的工作区。副本独立于后续来源变化。持有链接的人都可以访问。选中类型中的事件标题、介绍、地点和普通事件网址会分享，私密订阅来源地址和私有账号标识不会分享。接收者保存的副本无法召回。

订阅地址适用于支持 ICS 订阅的客户端。Google、Outlook 跳转是便捷入口，服务商界面与登录流程可能变化。没有预填地址时，请复制网址，按 [Google 通过网址添加](https://support.google.com/calendar/answer/37100?hl=en)或 [Outlook 从 Web 订阅](https://support.microsoft.com/en-us/outlook/import-or-subscribe-to-a-calendar-in-outlook-com-or-outlook-on-the-web)操作。刷新频率由客户端决定，导出的 ICS 文件是快照。

## 官方日期与运维

来源为 [OSU University Registrar 校历](https://registrar.osu.edu/academic-calendar/)的公开 `umbraco/api/calendar/getentries` 接口。采集覆盖上一年至未来五年，并合并重复的每日条目。包含一般假日、停课时段、session 边界和考试周，不推断单门课程的具体期末考试安排。明确停课日期会排除生成的上课事件；仅办公室关闭不会排除课程。每个日历可选择包含官方日期，导出只包含其日期范围内的内容。

```sh
pnpm user-data:migrate
pnpm user-data:migrate --apply
pnpm calendar:sync
pnpm calendar:sync --apply
```

命令默认预览，`--apply` 才会写入配置的数据库。开发使用 `_dev` schema。明确操作生产环境时，在生产数据库配置下加 `--production`。catalog 工作流会在搜索准备步骤之后独立同步校历，即使前面的来源步骤失败也执行；重试与响应校验会在来源故障时保留旧记录。需要监控工作流，不能假定所有外部来源始终成功。

私有 `calendar`、`calendar_link` 表属于 `osu_identity` / `osu_identity_dev`。规划备份保留同一份日历快照，支持账号同步与恢复的原子提交。公开 `academic_calendar` 属于 `osu_planning` / `osu_planning_dev`。按域 schema 备份会包含新表。维护会清理无主的私有日历，以及超过保留期的过期或撤销链接。

分享前，日历地址和事件属于账号私有数据。应用服务器可读取，未使用端到端加密；私密来源网址本身可能就是访问凭据。日历页面与浮层对回放内容脱敏，统计不会收集事件文本、来源网址或访问凭据。

无需上传文件的本地检查：运行 `node scripts/calendar/inspect.mjs /path/to/calendar.ics`，只输出事件数量和导出再导入的数量。离线回归命令见[测试说明](../testing.md)。

## 界面与导入行为

点击日程先打开锚定详情浮层；可编辑日历另有编辑操作。官方及订阅日程保持只读。手机端来源卡片采用一致尺寸，七个周标题始终处于同一行。生成分享链接后默认尝试复制一次；浏览器拒绝剪贴板权限时，仍可通过可见链接框手动复制。分享界面明确列出日历、类别选择与发布状态。

远程 DNS 固定连接同时支持 Node.js 单地址与自动地址族查找约定。包含 `#assignment_` 的 Canvas 链接会识别为作业。ICS 导入保留首个受支持类别（class、assignment、exam、holiday 或 event）；未知类别归为 event。导出保留规范化后的类别及 HTTP(S) 来源链接；零时长截止事项显示单个时间，不再重复相同的起止时间。
