# 界面动效与焦点

[English](../../design/interface-motion.md) · 简体中文

统一使用 `globals.css` 中的时长和缓动变量。页面、面板、页签、提示和操作反馈以透明度或 transform 动画为主，避免持续改变布局尺寸。页面入场后不保留 transform，以免固定和 portal 元素偏移；Vaul 自行管理抽屉拖动。

手机课程抽屉的拖动关闭区域是完整 32px 把手，正文保留独立纵向滚动和横向页签手势。键盘焦点采用清晰的单层提示，不给整个对话框额外系统外框。选择器、提示层需要进行碰撞避让。

`prefers-reduced-motion: reduce` 关闭循环加载器与移动反馈，缩短过渡，并让分页回顶立即完成。回顶按钮依据 visual viewport 避开提示、菜单和其他控件；模态或全屏覆盖时隐藏。布局跟踪使用观察器和有限动画采样，不常驻轮询。
