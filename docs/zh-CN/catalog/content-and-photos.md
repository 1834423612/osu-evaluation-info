# 课程内容与教师照片

[English](../../catalog/content-and-photos.md) · 简体中文

课程描述、先修条件、学分与班次来自官方课程服务；教师照片使用独立的受限接口。目录身份和实时选课数据分开处理，旧收藏可展示保留的课程说明，但不能冒充当前开课或实时空位。

照片请求仅接受已校验的 OSU 教师标识和固定来源，不接受任意 URL。不存在照片时保留头像缩写，不显示破图，不因图片缺失改变身份确认状态。缓存、失败状态与请求边界由人员／照片适配器统一管理。

修改字段展示时同时核对官方数据契约、课程卡片和详情；线上授课标记必须来自明确的授课方式或地点证据，不能只根据空地点推断。

## 命令与格式示例

以下示例与英文版使用相同命令、字段和参数；运行前按上文核对环境与影响范围。

```json
{
  "delivery": "osu-direct",
  "version": 1,
  "resource": "instructor-photo",
  "endpoints": { "photo": "https://opic.osu.edu/" },
  "width": 96
}
```
