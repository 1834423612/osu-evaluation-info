# 课程同步运维

[English](../../catalog/operations.md) · 简体中文

首次部署或升级时显式运行 `pnpm catalog:migrate`；计划任务不执行 DDL。同步使用独立 `osu_catalog` schema，按学期、校区和学科分区发现、分页、重试、核对计数，并将断点与数据一起提交。未完成任务默认续跑，`--new-run` 明确开始新一轮。

只有完整分区和父子身份校验通过后才能原子发布不可变版本。advisory lock 避免重叠；事务和连接有边界，不在外部请求期间持有长事务。失败扫描不能替换可用副本。

课程和班次版本永久保留，旧清理选项不删除已发布数据。每学期选择最近完整主版本；当前删改反映在新目录，旧收藏可恢复其最近完整历史副本。官方学期消失只改变来源状态，不清空本地归档。迁移第 4 版增加学期主版本与完整官方学期观察。

GitHub 课程任务按纽约时间每四小时调度。实际执行可能延迟，页面以同步时间为准。空位仍由浏览器实时查询，目录同步不能提供实时席位保证。更多恢复规则见同目录 `lifecycle.md`。

## 覆盖保护与恢复

升级同步器前运行 `pnpm catalog:migrate` 安装第 7 版迁移。数据库发布触发器也保护旧版同步程序：逐学期对照上一版被接受的目录，拒绝整个学期或校区消失、学期或校区 section 数减少超过 20% 且至少减少 20 个，以及单个校区学科减少超过 50% 且至少减少 10 个。小幅变化和新学期仍可发布。大规模真实撤课需要人工调查；计划任务没有绕过保护的开关。

官方总数自洽并不代表数据完整。2026 年 11 月 22 日，Spring 2027 的 Columbus 从 25,524 个 section 降为 10,931，Mansfield 消失；通过上一版完整归档恢复搜索。仅核对计数和摘要无法区分这类来源故障与真实删除。

先调查可疑发布，再应用恢复。将 `RUN_UUID` 替换为准确的运行 ID：

```sh
node scripts/catalog/recover_snapshot.mjs --run RUN_UUID
node scripts/catalog/recover_snapshot.mjs --run RUN_UUID --apply --backup .cache/catalog-quarantine.json
pnpm search:prepare
```

第一条命令只输出计划。应用要求检测到覆盖退化、每个学期都有前一版可用发布，且目标仍是相关学期的当前主版本。恢复持有维护锁，先以 0600 权限独占创建元数据备份，再通过事务把异常运行标为 failed。原始课程、section、发布标记、索引和变更历史都保留；隔离后的已发布源记录仍不可修改。查询与变更动态排除隔离版本，指向隔离版本的旧游标需要重启查询。完整数据库备份仍需单独保存：不可变历史和元数据恢复文件不能防止数据库丢失。

维护任务提前准备每学期最新及前一版可用索引，修复缺失资料；隔离索引不占可用保留名额，清理按发布时间排序。请求先验证已准备索引，再可在预算内读取同一不可变源快照。整个版本不能加载时，未固定游标的搜索最多尝试同学期两个较旧可用发布。元数据、连接等待、构建排队和详情共用 28 秒总预算，单版本读取最多 6 秒；分页不静默换版本，结果保留实际快照时间。搜索 CDN 缓存 30 秒，另有 60 秒后台重验证窗口。这些回退仍依赖数据库可连接；没有新增独立数据库副本或第三方索引。

学期列表中的 null 占位会被计数并忽略；其他异常学期或筛选项以明确的数据错误终止，避免写入。JSON 日志包含重试次数、端点、HTTP 状态、受限的学期／校区／学科／页码、发布差异和回退版本 ID；不记录查询正文、响应全文和数据库凭据。最终错误记录失败阶段并脱敏连接凭据。

请求超时为 30 秒，同步请求总预算为 20 分钟，为 30 分钟 workflow 留出维护时间。HTTP 传输错误、408、429、5xx 最多尝试五次，Retry-After 最多等待 30 秒；永久 HTTP 错误和异常响应封装直接失败。

课程 workflow 保持仅按纽约时间 00:17、04:17、08:17、12:17、16:17、20:17 调度，不增加 push、PR 或手动触发，也不执行迁移。摘要分别报告课程同步、RMP 映射、历史回填、索引和校历状态，并附各维护日志末尾 40 行，每行最多 1,000 字符；管道保留失败退出码。结构化错误还展示操作、来源请求、JSON 字段、期望／实际值、记录 ID 和校验器文件／行号；已核验的父子差异单独列表。同步失败后仍修复被接受的旧发布索引。历史回填预算或语句超时回滚未完成学期并记录延期，其他异常仍使任务失败。

官方父课程可能与当前班级的学科／课号不一致。受限调和要求选中学科筛选项的名称与班级两个学科名称一致，显式课程 ID 相同，学期、开课号、父级键有效，且班级两个课号字段相同。原父级身份保留在 `officialParentIdentity`；无法核验的分歧仍失败。另见[有日期的来源与存档对比](source-audit-2026-11-25.md)和[只读复现命令](scheduled-sync.md#排查失败的运行)。

运行时选取缓存 Node 24，必要时下载并校验官方 Node 24.18.1；pnpm 使用 `package.json` 固定的准确版本，当前为 12.18.0。课程 workflow 的 shell 检出核对准确提交，不需要放宽仓库 Actions 策略；私有仓库另需带身份的检出。
