# 课程同步隔离基准：2026-11-05

[English](../../catalog/sync-benchmark-2026-11-05.md) · 简体中文

该报告记录隔离同步的实际耗时、写入速率、应用响应与锁风险；数据只适用于当时机器、数据集和实现。测试使用独立存储和清理过程，不把合成压力当作线上并发保证。

报告确认：更新期间仍应保留上一个可用副本，不能在刷新开始时使旧回退版本失效；重复启动 DDL 即使列已存在也可能等待锁。迁移必须显式执行，正常同步不应夹带结构修改。

后续版本已经引入不可变发布、永久保留和学期主版本。此报告保留历史测量，当前行为以运维和生命周期说明为准。表中端到端响应与同步吞吐是不同指标；数据库连接、队列和外部服务延迟均影响结果。
