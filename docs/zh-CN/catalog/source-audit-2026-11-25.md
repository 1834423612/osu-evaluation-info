## 处理与复现

分页准备现在仅在官方选中筛选项、班级两个学科名称、显式课程 ID、学期、父级键、开课号和两个课号字段均一致时，采用班级的学科与课号。原父课程学科、课号和学科描述保留在 `officialParentIdentity` 中。核验通过的差异记录为 `catalog.parent_identity_reconciled`；无法核验的记录仍在该页写入前失败。覆盖保护和不可变存档继续生效。

错误记录包含具体操作、候选运行、分区、页码、官方网址、JSON 字段、期望／实际值、课程与班级身份，以及校验器文件和行号。传输错误额外保留 HTTP 状态、尝试次数和底层原因。Actions 注解定位到校验代码；摘要展示字段对比及已核验的父子身份差异。凭据脱敏，日志不输出来源正文。

只读检查一个完整学科：

```sh
node scripts/catalog/inspect-official.mjs --term 1272 --subject airsci
node scripts/catalog/inspect-official.mjs --term 1272 --subject airsci --compare-archive
node scripts/catalog/inspect-official.mjs --term 1272 --subject milsci --compare-archive
```

第一条命令只需已安装运行依赖及官方网络访问。`--compare-archive` 额外从环境或 `.env.local` 加载 `DATABASE_URL`，在只读事务中读取该学期最新已接受存档，报告身份新增、本次缺失及变化。检查限定一个学科，可附加 `--campus col`，命中数须低于 10,000，请求预算为两分钟。差异属于观察结果；异常数据以结构化错误退出。另见[定时任务诊断](scheduled-sync.md#排查失败的运行)与[测试说明](../testing.md)。
