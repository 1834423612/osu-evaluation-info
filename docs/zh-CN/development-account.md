# 开发账号关联

[English](../development-account.md) · 简体中文

关联功能连接两个已验证账号，用于在隔离数据库之间测试私密收藏、文件夹、规划报告和日历。不复制密码、会话、邮箱验证、公开分享或统计数据。开发和生产保留独立身份与 schema。

1. 两个环境应用 `pnpm user-data:migrate --apply`，生产使用其数据库配置并加 `--production`。
2. 开发服务器的 `DEVELOPMENT_PRODUCTION_ORIGIN` 设置为不带路径的生产 HTTPS 域名，未设置时回退到 `SITE_URL`。仅配置域名不会获得账号访问权。
3. 在生产账号“账号与设备 → 开发账号关联”生成配对凭据，将仅显示一次的值粘贴到已验证开发账号的关联表单。
4. 开发在同步时自动拉取生产数据，导航显示“开发账号”。开发修改不会自动覆盖生产数据。
5. 回写时点击“预览合并到生产”，检查数量与冲突路径，再选择“将这些修改合并到生产”。待同步收藏或未解决冲突会阻止操作。数据变化会使预览失效，需要重新生成。

合并使用稳定 ID 和三方基准，独立新增及字段变化会合并，竞争修改保留为冲突。在两个环境统一冲突字段后，下一次预览即可消除。生产在同一事务中比较规划版本和收藏游标，容量或版本失败会回滚整个账号变更。

凭据 30 天后失效，可在生产账号撤销，每个账号最多五个有效凭据。解除开发关联只移除保存的凭据，不删除任一账号的数据；完全停止访问需要撤销生产凭据。

生产保存凭据摘要，开发后续拉取需要使用凭据，因此用服务器私有密钥派生的 AES-256-GCM 加密保存副本。服务器可以解密，不属于端到端加密。轮换 `USER_DATA_SECRET` 会使关联失效，需要重新配对。关联会有意复制私有数据，应限制开发数据库访问。

私有 `development_grant`、`development_link` 表属于 `osu_identity` / `osu_identity_dev`，包含在域备份中，过期、撤销或无主时会被清理。远程接口验证账号存在且已验证，并限制请求频率、耗时和字节数，只使用配置的单个生产域名，不跟随重定向。

[集成测试](testing.md)使用内存数据和模拟生产传输。真实关联前两个环境都必须部署接口，仅预览版无法连接尚未包含接口的生产版本。
