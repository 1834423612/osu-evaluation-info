# 官方评价全量数据质量报告

[English](../../../evaluations/data-quality/profile-report.md) · 简体中文

该报告对导入的完整 SEI／SSLE 数据进行剖析，保留自然键、合授、量表、标准差、更名、部门变化、N/A 编号、班级规模及字段覆盖证据。所有分布和比例对应报告数据集，不能当作线上实时统计。

核心模型结论：显示姓名不能作为教师身份主键；课程标题和部门会变化；合授教师记录不是重复回答；不能从邀请人数重建官方班级规模分类；不同量表不得混算。标准差修正和异常值需要追溯原始字段，不能仅凭列名猜测含义。

按学期、校区、授课方式和缺失字段核对后，数据模型使用稳定身份与来源保留显示历史。导入前应重新运行剖析与键校验，不能只抽查几门课程。本页保留原报告的数值示例与查询格式供复核。
