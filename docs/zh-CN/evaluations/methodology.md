# 官方评价计算方法

[English](../../evaluations/methodology.md) · 简体中文

SEI 和 SSLE 分开汇总。课程历史按学科、完整编号和校区匹配；教师分数还需要同一课程内精确匹配 OSU 邮箱。RMP 独立展示，不进入官方量表总分。

量表内汇总按回答数量和时间加权，时间半衰期为两年；两年前的证据权重减半。学期趋势点只按回答数加权。覆盖度是证据量和分布，不是统计置信区间；回答数不等于不同学生数，合授班次可有多条教师班次记录。

方向性提示至少需要 30 个原始回答与 30 个时间加权回答、2 条教师班次记录、2 个学期及两年内观察。缺失、样本不足与高低分分开显示，不制造零分。评分阈值与颜色由版本化策略和回归测试共同约束。

API 批量读取课程摘要，图表按需加载；输入、数量与数据库查询有边界。原始报告的标准差和其他数值字段保留来源定义。更多题目与量表说明在网站 OSU 课程说明中独立维护。
