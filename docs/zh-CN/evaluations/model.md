# 官方评价数据模型

[English](../../evaluations/model.md) · 简体中文

PostgreSQL 将原始导入证据与规范化课程、班次、教师、量表事实分层保存。课程自然身份使用学科、完整课程编号和校区；同一课程标题可以变化。部门不是不变的课程主键；合授班次允许多个教师事实。

教师跨来源身份以官方 `name_dot_number`／邮箱为主，姓名是可变化的显示值。SEI 和 SSLE 保持来源、题目顺序、量表和报告字段，不根据当前问卷的不同尺度重新推算历史报告均值。

增量导入需要校验记录数、自然键、外键、数值范围和父子关系，保存运行状态并支持回滚恢复。源站不再列出的历史资料不应直接清空本地记录。

课程目录、人员、RMP 和官方评价通过显式的来源身份与证据关联，不以相似标题或同名强行合并。当前生命周期、评分和导入命令分别见同分类说明。
