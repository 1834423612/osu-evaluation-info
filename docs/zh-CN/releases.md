# Release 与版本管理

[English](../releases.md) · 简体中文

[GitHub Releases](https://github.com/1834423612/osu-evaluation-info/releases)标识产品里程碑，网站构建信息另用准确提交号标识部署版本。创建 Release 不代表其代码或数据库迁移已部署。

## 版本规则

标签采用 `v主版本.次版本.补丁版本`，遵循[语义化版本](https://semver.org/lang/zh-CN/)。兼容的功能里程碑增加次版本、补丁归零；兼容的问题修正增加补丁。若已文档化的 HTTP 契约或保存数据／导入导出格式发生不兼容变化，应增加主版本并提供升级说明。内部重构、提交数量和日期不直接决定版本号；即使产品升级保持兼容，也应说明所需数据库迁移。

## 展示与发布流程

GitHub Release 名称与标签完全相同，例如 `v1.7.1`。数字部分不固定宽度，也不补前导零。介绍第一行用 Markdown 一级标题放功能标题（如 `# 学期规划`），随后放中英文更新说明、来源日期、迁移提示和版本对比链接。

除非任务明确指定其他发版边界，完成新功能或修复时应同时完成发布：

1. 对发布结果运行 `pnpm test`、`pnpm lint` 及相关类型、构建、集成或浏览器检查。必需检查失败时停止发布，准确说明主动跳过的外部服务检查。
2. 比较上个版本，选择下一个语义化版本，并对齐 `package.json` 和双语历史；需要迁移时说明运维操作。
3. 将功能标题和面向用户的变化写入介绍，Release 名称仅保留版本号。
4. 提交并推送已验证结果到主分支，将版本标签准确指向该提交后发布；核对远程标签、名称、正文和 Latest。

仅文档或 Release 展示调整可以直接修改对应文本，不另发软件版本。已发布标签保留原提交指向。另见[贡献者发版要求](../../AGENTS.md#releases)。

## 历史补建

保留现有 `v1.0.0`、`v1.1.5` 标签及 Release 记录。缺少 `v1.1.0`–`v1.1.4` 不代表这些版本曾经发布。后续里程碑按主分支集成顺序划分，包含已合并的功能分支。历史提交保留原有 package 元数据。

后续八条 Release 记录于 2026 年 11 月 26 日补建。下表代码日期采用 `America/New_York`，GitHub 发布时间记录实际创建条目的时间。历史条目总结源码变化，不表示每个旧版本都在其代码日期重新测试或部署。当前 `package.json` 对齐 `1.7.1`，部署仍以构建 SHA 和构建时间识别。

## v1.7.1 — 课程同步诊断

### 修复与改进

- 官方父课程资料与班级资料不一致时，保留经核验的班级学科及课号；显式检查和原父级来源信息防止不确定身份被静默接受。
- 同步错误明确记录操作、请求、页码、JSON 字段、期望／实际值、记录 ID 和校验文件／行号；Actions 摘要保留已核验差异，并脱敏连接凭据。
- 用只读命令对比官方学科与已接受存档，覆盖校区变化。
- package 元数据对齐 `1.7.1`，补齐中英文版本历史。

### 运维说明

课程修复于 11 月 25 日提交，版本历史和 package 元数据于 11 月 26 日对齐；不新增数据库迁移。另见[同步诊断](catalog/scheduled-sync.md#排查失败的运行)。重跑旧 Actions 任务使用原提交，参见 [GitHub 重跑规则](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/re-run-workflows-and-jobs)。

## v1.7.0 — 独立规划与课表控制

### 新功能

- 保留多个独立规划工作区，通过限定范围的链接分享选定学期计划。
- 在完整周视图中比较灵活课表方案，在官方记录旁保留个人修课标签。
- 用更清楚的日历课表视图查看事件，配置多个设备提醒。

### 改进与修复

- 模拟排课时刷新官方席位，恢复自动／固定选择，并保留窄屏日历来源预览。
- 按课程、学期、校区组织分享收藏，简化复制链接后的反馈。

### 运维说明

计划链接需要 `20261123_planning_shares.sql`。用 `pnpm user-data:migrate --production` 预览生产迁移，审阅并备份目标数据库后再应用。另见[规划运维](planning/guide.md)。

### 运维说明

## v1.5.0 — 培养方案与学期规划

### 新功能

- 根据本地处理的 PDF 候选项建立私有学期计划，审阅提取结果并保留来源上下文。
- 浏览官方培养方案存档、要求分支、替代选项和已检查的学期示例。
- 在学期间移动课程，查看目录详情，比较受学业负担限制的课程组合。
- 模拟班级课表并检查冲突，恢复可携带备份，同步账号规划。

### 改进与修复

- 保留重复要求、未通过记录及替代路径，改进移动弹窗与课表控件。
- 要求使用该里程碑附带的已修补 Next.js 依赖版本。

### 运维说明

启用账号存储前应用[规划迁移](planning/guide.md)，提供模板前发布已审阅的模板。导入和推荐需要审阅，不属于官方毕业审核，也不保证完整来源覆盖。

## v1.4.0 — 账号、收藏夹与跨设备同步

### 新功能

- 用邮箱验证码、通行密钥或可选密码登录，并提供一次性恢复码。
- 按收藏夹／标签组织收藏，选择性导入导出，恢复私有备份。
- 用排队操作及明确冲突选择跨设备同步，用批准配对和可撤销链接转移内容。
- 检索／导出本地活动，翻译完整大纲并导出中英双语 PDF。

### 改进与修复

- 并发编辑、容量不足及账号部分不可用时保留内容，保护未完成表单。
- 新增主动提交的诊断报告与管理员统计，分别控制存储及保留。

### 运维说明

自行部署需配置[账号运维](user-data.md)中的账号／用户数据结构及认证／邮箱设置。备份数据并审阅迁移后再应用；来源存档与私有用户数据分别保留。

## v1.3.0 — 搜索、教师资料库与永久存档

### 新功能

- 在课程目录中识别查询意图、容错检索，将精确课程代码查询发送至 OSU。
- 浏览教师来源档案和带课程标签的评价，区分已核验／未确认身份。
- 永久保留课程和大纲历史，维护学期入口并恢复已移除课程的详情。
- 查看根据完整快照生成、可筛选的课程更新记录。

### 改进与修复

- 跨校区核对课号并保留不同来源档案，改进面板滚动与导航。

### 运维说明

应用该标签的课程、大纲及 RMP 资料库迁移。永久存档增加存储用量，需要独立备份；来源标签不能单独确认教师身份。另见[课程生命周期](catalog/lifecycle.md)及 [RMP 资料库](rmp/library.md)。
