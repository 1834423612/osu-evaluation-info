# 本站统计与诊断

[English](../../analytics/first-party.md) · 简体中文

这套服务独立于 Umami。普通事件受统计设置控制；收藏在启用账号同步后上传；诊断值仅在预览并提交报告后上传。Umami 回放在所有页面沿用远端配置，包括账号、收藏、历史和分享页面。

## 事件与请求信息

事件包括页面访问、提交的搜索、搜索结果与耗时、实际打开的课程、收藏增删和分享导入。字段结构固定，不接收任意表单值、凭据或链接片段。课程代码会统一格式；疑似凭据和邮箱会脱敏。跨标签通知、云端镜像和相同事件 ID 的重试不会重复计数。

浏览器通过 IndexedDB 暂存最多 500 个事件，本地保留 24 小时，每批最多 20 个，失败后按受限退避策略重试。统计故障不会阻止搜索和收藏。主动关闭统计、Do Not Track、Global Privacy Control 和调试工具的统计开关均会阻止采集。

请求信息包含完整 User-Agent、Accept-Language、浏览器上报的语言与时区、视口尺寸分组、环境，以及可信代理配置允许时的 IP。随机安装标识在入库前经 HMAC 处理，不是账号凭据。浏览器值不能证明用户身份。

只有入口代理会移除用户传入的同名头、并覆盖为一个验证过的地址时，才能设置 `USER_DATA_TRUSTED_PROXY_HEADER`。例如，`x-real-ip` 只有在这种部署约定下才可信。地址列表和未经指定的 `X-Forwarded-For` 不会被使用。未配置时，IP 记为不可用。

统计使用独立的两个 PostgreSQL 连接，限制等待队列和语句耗时。事件写入和每日计数通过同一条原子 SQL 完成。每日汇总使用 UTC；环境筛选区分生产、预发布和开发。

## 统计页面

通过 Dev Tools 的“统计与诊断”分区打开 `/admin/statistics`。生产 API 要求用 `DEV_DEBUG_KEY` 解锁后获得的管理端签名会话。前端显示状态不授予 API 权限。本地开发默认允许调试。

页面提供 1～90 天汇总、前 50 个搜索词、结果与耗时分布、访问页面、分享链接累计计数、请求信息和诊断报告。请求记录每页 100 条，报告摘要每页 25 条。游标保留时间戳微秒，并以 ID 区分相同时间。完整诊断数据只在打开报告时获取。JSON 导出仅包含当前展示的结果，不进行无限量数据库导出。

`/popular` 按已同步账号当前保留的收藏计数，同一账号的同一个规范项目计一次，移除收藏会减少计数。无法确认身份的教师姓名不会被合并。匿名本地收藏和分享次数不代表收藏人数。公开响应仅包含精简的课程／班次快照和教师标签，移除联系方式，最多缓存一分钟。

## 浏览器诊断

`/diagnostics` 包含参考项目 [Who Are You 清单](https://github.com/yt1988/who-are-you/blob/cabe524f4cc944dd7c62a30582a395132a4132d6/src/sniffers.mjs) 的全部 133 个项目。MIT 声明保留在 `src/lib/diagnostics/UPSTREAM-LICENSE.txt`。检测代码由本站单独实现；清单中的方法名描述上游能力，不承诺测量方式完全相同。

- 基础项仅在点击“开始检测”后执行。设备／指纹和网络检测分别选择启用。
- 定位、运动传感器和键盘布局单独执行，按浏览器要求申请权限。摄像头／麦克风只列出可见的设备类型和名称，不申请录制权限，不读取生物识别样本。
- EXIF 在本机读取用户选择的 JPEG，文件最多 20 MiB，元数据读取最多 256 KiB，原文件不会上传。存储检测仅展示本站数量，不读取存储原文。标签历史仅提供 `history.length`。
- 耗时工作受限。栈深度检测在可终止的 Worker 中运行，音频指纹使用离线渲染。Canvas、字体和硬件组合值可被伪造，不是序列号或登录凭据。
- 每项显示来源及状态：已读取、不支持或未提供、权限被拒绝、被阻止、超时、失败、未配置或未运行。缺失值不会变成零。扩展痕迹不能枚举全部扩展；字体仅检查明确列出的样本。
- 先选择项目、预览实际 JSON，再提交。批量选择排除 IP、局域网地址、精确定位、传感器和照片信息，这些项目可单独选择。报告包含版本号，最多 133 个不同项目，每个值最多 16 KiB，每次提交最多 512 KiB。

服务器将提交值标记为“浏览器上报”，并单独保存独立观察到的请求字段。提交 ID 可安全重试，并绑定提交会话。报告超过七天后无法通过管理端 API 访问；物理删除依赖下面的维护任务。

### 可选探针设施

CDN 后的 Next.js 源站无法还原浏览器的传输细节。缺少受控设施时，这些项目显示“未配置”。应用不会调用参考项目的公共探针服务。

`DIAGNOSTICS_TRUSTED_HEADERS` 接受 JSON 映射，例如 `{"ja4":"x-diagnostic-ja4","edge":"x-diagnostic-colo"}`。仅接受清单允许的项目及 `x-diagnostic-*` 请求头。入口必须移除传入的同名值，改为浏览器到边缘连接实际观察到的值，不能用源站自身的 TLS 信息冒充访客指纹。

`DIAGNOSTICS_PROBE_PATHS` 将支持的网络项目映射到专用路径，例如 `{"dns":"/diagnostic-probes/dns"}`。路径必须以 `/diagnostic-probes/` 开头，后续仅使用字母、数字、斜杠、下划线或连字符。浏览器不带凭据和来源信息请求，截止时间四秒，JSON 响应最多 16 KiB。应用不会请求访客传入的任意 URL。

这些路径由运营者提供适配器，不是内置传输探针。适配器必须返回能够归属当前浏览器的测量。服务器的出口 IP 不能代表浏览器的出口。DNS、跨站、扩展和追踪拦截检测需要受控目标、浏览器侧测量，以及必要的隔离和 CORS 支持。设施不可用时应保留不可用状态，不要返回成功的占位值。

## 安装与保留期

配置认证／用户数据密钥、备份数据库后，执行增量迁移：

```sh
pnpm account:migrate --production
pnpm account:migrate --production --apply
pnpm user-data:migrate --production
pnpm user-data:migrate --production --apply
```

未加 `--apply` 时仅显示只读计划。开发默认使用独立认证表和 `osu_user_dev`，生产使用 `osu_user`。覆盖命名空间前请阅读[账号部署](../user-data.md)。

| 数据 | 保留期 |
| --- | --- |
| 安全事件、完整请求信息、诊断报告 | 7 天 |
| 原始产品事件 | 30 天 |
| 非空维度的每日统计，包括搜索词 | 90 天 |
| 无维度每日总数 | 保留 |
| 过期／撤销的分享快照 | 7 天清理缓冲 |
| 过期／完成／撤销的转存 | 1 天清理缓冲 |
| 同步回执和删除墓碑 | 至少 180 天 |
| 有效收藏、官方课程／大纲归档 | 此任务不删除 |

```sh
pnpm user-data:maintain --production
pnpm user-data:maintain --production --apply
```

第一条仅预览。实际清理会检查安装归属标记，只锁定自己的维护任务，分批删除并报告剩余工作。墓碑清理在事务中推进账号的重新核对边界；游标过期的设备必须先核对合并，才能恢复本机项目。

仓库变量 `USER_DATA_MAINTENANCE_ENABLED=true` 启用后，`.github/workflows/user-data-maintenance.yml` 每四小时执行。定时清理**默认关闭**。手动触发默认也只预览，选择 apply 才会删除过期数据。`DATABASE_URL`、生产命名空间和认证表前缀须与应用一致。启用计划前先执行迁移。任务执行前，即使报告 API 已禁止访问，过期行仍可能留在数据库中。数据库备份另有保留策略。
