# 2026-11-13 全校区教师身份核验

本轮针对原先未关联的全部 **7,758 条 RMP 档案**执行官方人员查询，
每个姓名另有独立网页检索记录，并补查院系页面与历史 PDF。
这是来源辅助的全量核验，不表示人工逐页阅读所有搜索结果，
也不把检索无结果解释为此人从未在 OSU 任教。

## 来源、缓存及分类

- 官方人员主查询覆盖 7,758 条；第二官方接口补查 6,722 条；
  另对 1,555 条档案的候选账号执行精确账号查询。
- 对每个姓名执行独立网页检索，尝试核验 4,511 个不同官方 HTML 地址，
  以及 1,112 个聚焦的官方历史 PDF 地址。失败、不可解析、截断结果均
  保留状态，不能当作成功读取的空记录。
- 官方人员缓存目前共 3,038 个账号：OSU Search 2,026、旧人员 API 787、
  经联系区块核验的院系页面 225。这个总数包括候选账号，不等同于新增关联数。
- 当前职务仅取明确的官方任职信息；历史 PDF 的旧职务单独保存，
  不写成现职或当前人员缓存。无法证实的员工类型保持未知。
- 全部 7,758 条档案的判定及来源证据已保存到服务器研究表，
  包括全部未解决记录。原始 RMP 档案和评价没有合并或改写。

## 永久归档范围

课程和教学大纲数据库均已安装第 3 版归档保护。完整发布的课程/班次
快照、大纲索引和正文历史版本禁止删除、清空或覆盖，计划任务不再
清理旧课程快照；官方删除旧学期不会删除这些已抓取副本。
核查时服务器已保存 8,322 份不同大纲的正文，含 9,181 个正文版本。

尚未抓到或过去已删除的内容不能凭空恢复。当前大纲归档保存 HTML
正文及结构，外部图片、字体和上传附件尚未作为二进制离线副本归档；
永久保留数据库记录不等于完整离线媒体镜像。
