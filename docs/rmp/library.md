# RMP 教师库与待确认评价

## 页面职责

`/rmp` 搜索所有已保存的 RMP 档案，可按校区、姓名、院系、原始课程代码、
已有课程别名关联及官方身份确认状态筛选。

`/rmp/[id]` 展示某份原始 RMP 教师档案及其全部课程评价。
桌面使用课程侧栏，手机使用紧凑课程选择器；原始课程标注单独保留，
例如拼错或缩写不同的代码不会在教师页悄悄合并。
支持按课程过滤、分页、浏览器返回、原站链接、教师回复及原始评价详情。

这个页面服务于跨课程查看教师，不复制课程目录、官方评价趋势或班次查询。
入口位于“课程说明与数据”菜单；课程评价内也可跳转该教师的全部课程评价。

## 未确认身份的评价

课程详情继续区分两组数据：

1. 已确认身份，并能关联当前教师选择或官方任课历史的评价。
2. 其他 RMP 档案：本校区的课程标注匹配，但官方身份或任课记录待确认。

两组共用课程内的教师评论卡片，均可展开、翻页、翻译和查看详情。
已确认的任课关联排在前面；第二组按实际情况显示“身份待确认”或“任课关联待确认”。
查看当前课程的评论无需跳转，教师完整档案链接用于跨课程浏览。

课程卡片的汇总评分、难度和关键词只采用身份及任课关联已确认的档案。
待确认档案即使是唯一数据来源，也只在自己的教师卡片显示评分，不计入课程总分。
没有已确认评分时保留未确认档案的数量与入口，不制造零分或混合均分。
个人教师评分接口仍限制在所选官方账号，不能把其他待确认档案的评分分配给该教师。
评论面板的教师主评分优先近两年；近期没有样本时显示本课程历史均分，并显式标注历史。
近期样本仍为零，不将旧评价改称新评价。课程卡片的既有近期综合分口径保持独立。

课程线索只使用同一 RMP 校区中的精确课程代码或已有证据支持的课程关联。
不会仅凭姓名相近、课程号片段或其他校区的评价强行挂到当前课程。
身份已确认而任课记录不足时，标签为“任课关联待确认”，不错误标成身份未知。
课程历史查询直接覆盖同校区、同一规范课程代码下的全部 RMP 档案，不要求先确认教授身份。
分页与预览使用相同的档案选择条件；未知姓名不能生成虚构的 OSU 邮箱。
没有课程评价的搜索卡片保留文本入口，不增加空结果插图。

## 单条评价字段

课程面板和教师库共用评论组件，显示综合、帮助度、清晰度、难度和是否愿意再选。
成绩、出勤、教材使用、线上课程及计学分记录在折叠详情内；已有教师回复也完整显示。
赞同／不赞同是带无障碍名称的只读原站数量，没有投票请求或可操作按钮。
缺失值与实际的 `false`、`0` 分开保留。负数教材占位显示未填写；未文档化的数字枚举
保留 `n (RMP)` 原值，不猜测成“使用／不使用”。预览和分页不截断原始评论。

评分含义参见 [RMP 评分说明](https://help.ratemyprofessors.com/article/31-rating-scale)。

## 完整留存

原始教授、评价和校区关系增加防 DELETE/TRUNCATE 保护。
无法关联身份不会触发源数据删除。采集器确认源站移除后可以更新软状态，
但教师库仍能读取留存资料，并明确标注原站已归档或评价已移除。

普通课程评分仍排除原站已移除记录。教师页的 RMP 原站均分来自原始档案，
不使用不确定历史补充重新计算。尚未对上不可变 RMP 评价 ID 的旧补充资料
在单独折叠区显示，不重复计入数量或评分。

安装保护：

```sh
pnpm rmp:library:migrate
```

## 刷新与实时性

访问页面读取本站数据库；教师列表每页 24 份，评价每页 12 条。
接口允许短期缓存，页面显示实际资料同步时间。“重新读取”读取本站副本，
不假装实时抓取 RMP 官网；原站链接可以直接查看官网当下内容。

新增 `.github/workflows/rmp-sync.yml`：

- 按工作区设置，目标为纽约时间每周六 03:30。
- 每次最多 600 个请求、每批最多 20 位教师，间隔至少 10 秒，默认刷新变化档案及超过 7 天未核验的评价页。
- 达到限额保存断点，下次继续，不通过 `--new-run` 丢弃进度。
- 不在用户每次访问时发起采集，不用浏览器访问量驱动大规模抓取。
- 采集后重新计算官方身份和课程代码关联；已有明确人工决定保留。
- 与其他关联任务冲突时有限重试；持续冲突时保留已采集数据，由课程定时任务继续关联。
- 当前身份规则无法确认的新档案立即可以在教师库浏览，不必等待身份确认后才显示。

每周一次是任务调度计划，不保证所有资料都在当次任务中完成刷新；请求预算、源站故障、
积压和调度延迟均可能延长时间。因此以各档案显示的同步时间为准。
GitHub 的定时任务可能延迟，见[官方 schedule 说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。

官方课程每四小时同步，官方大纲每日同步；这三类数据源有独立的时间和状态。

## 接口与验证

- `GET /api/rmp/professors?q=&campus=ALL&identity=all&offset=0`
- `GET /api/rmp/professors/[id]?course=MATH1131&offset=0`
- `GET /api/rmp/course/leads?subject=MATH&catalog=1131&campus=MNS&scope=course-history`

输入、页大小和 offset 有明确边界；所有 SQL 值使用参数。
失败返回不可用状态，不伪装为无评价。档案详情在同一只读事务中读取，
避免数量、课程列表和评论分页来自不同快照。

真实数据库测试验证全部校区、未确认档案、原始课程过滤、分页去重、
历史补充、原始数据保护和已确认评分隔离。
浏览器测试覆盖双语、320/390/768/1440px、返回导航及真实 Mansfield 评价线索。

```sh
RMP_INTEGRATION_TESTS=1 node --env-file-if-exists=.env.local --test tests/rmp/*integration.test.mjs
node tests/rmp/library.browser.mjs
node tests/rmp/course-leads.browser.mjs
```

浏览器脚本接受 `PLAYWRIGHT_MODULE`、`PLAYWRIGHT_CHROMIUM_EXECUTABLE`、
`RMP_TEST_BASE_URL` 和 `RMP_TEST_OUTPUT`。

## 分区与显示方式

课程面板按当前学期的官方班次名单区分“本学期教师”和“历史评价”，不是按评论日期猜测任课学期。
邮箱精确对应优先；唯一的规范化全名只用于把待确认档案放入对应分区，不提升身份确认状态。
历史 SEI／SSLE 名单不当作当前任课名单。身份状态、邮箱、评分和标签采用独立流式布局。

教师库首页提供网格／列表切换，使用 `course-atlas:rmp-view:v1` 在本机保存。
存储不可用时仍可在本页切换。卡片和详情保留原站评分、难度、再选比例、评论数量及身份状态；
缺失比例的 `-1` 不显示成负百分比。详情课程导航在桌面为侧栏、手机为选择器。
