# OSU Frog – Expression Assets

Three separate transparent-background frog character assets with Ohio State–inspired scarlet varsity outfits.

* `01-salute` — two-finger salute
* `02-belly-laugh` — laughing with both hands on the belly
* `03-pointing-laugh` — laughing and pointing to the right

For each pose:
* `-transparent.png`: cropped native-resolution transparent PNG (no artificial upscaling)
* `-256.png`, `-512.png`, `-1024.png`: square, transparent PNG, centered with safe padding
* `-512.webp`, `-1024.webp`: smaller WebP assets with transparency

Recommended usage:

```html
<img src="/assets/02-belly-laugh-512.webp" alt="Laughing OSU-themed frog mascot" width="256" height="256" />
```

The simplified Block O patch and color palette are OSU-inspired. This is unofficial fan artwork; ensure you have rights/permission for any protected character and university trademarks used in public branding.
